# Remove an AI Prompt from the Library

Removes a prompt from the prompt library.

## Usage

``` r
ai_prompt_remove(name)
```

## Arguments

- name:

  Name of the prompt to remove.

## Value

Invisibly returns the updated prompt library.

## Examples

``` r
if (FALSE) { # \dontrun{
# Remove a prompt
ai_prompt_remove("tidyverse")
} # }
```
